About RecipeHub

RecipeHub is a Progressive Web App built with HTML, CSS, JavaScript and a Service Worker. It caches every required resource so the app keeps working without a network connection.

What is stored offline

  • Home and About pages
  • The custom offline screen
  • style.css for the complete design
  • manifest.json and app icons

Features

  • Works without an internet connection
  • Can be installed on the home screen
  • No sign up required
  • Lightweight and fast
